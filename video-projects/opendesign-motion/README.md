# OpenDesign Motion — reference reconstruction V3

This is a dedicated motion-design project inside the multi-genre Nolane Video ecosystem. It is separate from the H2 SelfImprove Studio narrative pipeline and the existing One More Scroll composition.

## Reference facts

The source supplied by the user is 37.312 seconds, 1920×1080, 30fps. It must remain outside public repository history. We use its scene order, pacing, design language and transition grammar as the reference; the artwork and soundtrack in this project are newly authored.

## V3 direction

V3 replaces the V2 generic poster-card / invented dashboard approach with a shot-by-shot rebuild of the actual reference structure:

- 0–3s: cloud horizon, editorial headline and typed prompt.
- 3–4.5s: oversized OpenDesign MOTION title.
- 4.5–5.5s: radial mark and Claude Motion reveal.
- 5.5–7.5s: open-source positioning line and lime highlight.
- 7.5–10.5s: individual artwork in a deep perspective gallery.
- 10.5–19.5s: rapid 12-beat poster sequence (comic, MIND, concentric type, collage, IN, NEVER/LINEAR, 1889 clock, toggle, 3.7% eye, second comic and 3D type).
- 19.5–21s: “Not just Opus 5.5” on black.
- 21–25.5s: Any model / Any agent.
- 25.5–30.5s: Launch Kit UI with prompt/model controls and changing previews.
- 30.5–32.5s: 3–2–1 countdown inside the same UI frame.
- 32.5–35.3s: textured multi-face 3D cube.
- 35.3–37.3s: final OpenDesign Motion lockup.

The visual beat map and scene-level quality gates are in `shot-map.json`.

## Rendering

- Remotion 4.0.538
- Composition ID: `OpenDesignMotion`
- 1920×1080, 30fps, 1,119 frames
- Display faces: self-hosted Inter Variable and Space Grotesk Variable packages
- Score: original procedural 115 BPM composition, not the source soundtrack
- The project is rendered by `.github/workflows/render-opendesign-motion.yml`

The workflow validates TypeScript, render completion, MP4 metadata, AAC stereo 48kHz audio, loudness / true peak, SHA-256 and full 1fps / 2fps review sheets. A technical pass does not equal artistic approval.

## Review criteria

Review the moving MP4, not just stills. Pay special attention to:
1. The opening UI / typography scale and reading rhythm.
2. Poster art identity and cut timing.
3. The UI frame remaining coherent while preview contents change.
4. Countdown staying inside the app preview.
5. The cube's silhouette, visible faces and camera movement.
6. Audio impact placement and the final lockup hold.

The reference is not copied frame-for-frame; this is an independently authored reconstruction. Do not describe it as a pixel-identical reproduction.
