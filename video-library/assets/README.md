# Cross-genre video asset library

This is the shared asset pool for future videos, not a collection dedicated to the self-improvement channel. It separates three classes so later projects can reuse resources without guessing at rights:

1. **Bundled / redistributable** — original assets generated by this repository and source packs whose public page explicitly identifies the pack as CC0. Each downloaded item gets a provenance record and SHA-256.
2. **Use-in-video, source-only** — free stock footage, music, and other media whose terms allow incorporation into a finished film but prohibit redistributing the raw files as a standalone pack. The source URL and restrictions live in the catalog; the builder does not download these into our release ZIP.
3. **Review required** — anything with a non-CC0 license, unclear provenance, people/brand restrictions, or license metadata that cannot be confirmed. Do not bundle automatically.

## Release deliverables

The Actions builder generates a versioned downloadable ZIP containing:
- Original vector background library across documentary, science, news, history, travel, nature, gaming, product, food, finance and narrative genres.
- Transparent motion-graphics overlays / VFX.
- Reusable icon SVGs and infographic / title / lower-third templates.
- Curated Kenney CC0 packs (2D sprites, 3D props/environments, VFX and audio).
- Eligible Openverse **CC0-only** image/audio downloads, with each item's creator, source page, license URL, file hash and size recorded.
- Poly Haven CC0 environment/model downloads when the live API returns a valid supported file; failures are recorded rather than silently misrepresented.
- `ASSET_INDEX.json`, `SOURCES_AND_LICENSES.md`, and `SHA256SUMS.txt`.

Large binary assets are shipped as a GitHub Release asset, not ordinary Git blobs. The source code, catalog, generated-original SVG source templates and selection rules remain versioned here.

## Usage

Use `GENRE_PLAYBOOK.md` to select a visual language first, then search by category and combine only assets that help the story. Do not make every film look alike by swapping the title over the same background. Mix source media, purpose-built environments, real 3D models, diagrams, and custom composition when the genre calls for them.

The download workflow is intentionally rate-limited and size-capped. A partial third-party failure should show in the index; it must never be reported as a complete pack unless checksums and counts confirm it.
