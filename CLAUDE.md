# Claude Code instructions

Before any video work, read `AGENTS.md` and `.agents/skills/video-production-master/SKILL.md`. Then read `docs/STATE.md`, `docs/AI_HANDOFF.md`, and the active project's manifest/shot plan.

Treat `.agents/skills/video-production-master/SKILL.md` as the canonical production skill. The adapter at `.claude/skills/video-production-master/SKILL.md` exists so Claude Code can discover the workflow; do not fork or silently diverge the rules.

On the established self-improvement film series, the user prefers cinematic stick-figure storytelling with simple characters, richly staged environments, motivated camera/acting, believable hand/foot contact, restrained practical lighting and deliberate sound. Preserve that style for that series; do not impose it on unrelated genres. For new briefs, choose the visual grammar appropriate to the requested format (documentary, explainer, product demo, tutorial, interview, 2D/3D animation, short-form, etc.) while avoiding generic templated visuals.

Never claim a renderer ran without logs; never equate H2 Canvas output with the separate Remotion build. Review contact sheets and motion proofs, not just CI status. At handoff update the current state, film manifest, QA, and source/artifact links.
