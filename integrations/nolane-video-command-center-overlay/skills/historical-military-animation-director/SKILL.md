# Historical Military Animation Director

## Route boundary
This is a genre-specific H2 Squire route, not the default for every historical or military documentary. Use it only when the user explicitly asks for the established H2 Squire vector grammar or an existing Squire series: symbolic round-headed figures, historically grounded armor/clothing, vector horses/army formations, parchment maps and tactical diagrams.

For footage-led, cinematic, high-motion history with archival footage, 2.5D/3D scenes or diverse live-action-inspired camera work, use historical-cinematic-documentary-director instead. Do not try to imitate that visual language with repeated vector soldiers, sword props and boards.

Use the separate private h2-squire-studio plugin for detailed engine procedures. Host activation remains explicit; never claim that the Command Center silently invokes another private plugin.

## Engine selection
- H2 Squire is primary only for an explicitly requested Squire/vector film.
- Remotion remains a separate timeline/compositing engine; never call it the Squire renderer.
- Blender is conditional for genuine 3D depth, camera, physics or a model that materially improves a shot.
- Krita is conditional for painted maps, textures or frame-by-frame additions.
- FFmpeg/ffprobe handle audio finishing and technical checks.

## Research and visual direction
Establish event/date/place, distinguish fact from estimates/contested views and keep a claim/source ledger. Preserve character continuity. Vary wide, medium, close, inserts, reaction and overhead views. Show anticipation → action → contact → follow-through → recovery. Make cause/effect visible. Use tactical diagrams only when narration explains tactics; avoid maps/labels as generic filler.

## Voice and sound
Use VoiceStudio's GitHub Actions workflow when narration is requested and the voice has an appropriate rights record. Search the existing recorded-sound library before any synthesis. Use real licensed Foley, ambience, impacts and score where suitable; procedural audio is a placeholder only. Keep source/license data, stems, attribution and hashes. No commercial music extraction or unauthorized voice cloning.

## QA and handoff
Prototype the hardest action, preview the moving sequence and listen to the mix. Require full-length playback with sound and a timecoded defect log before publication. Technical checks and contact sheets do not equal visual approval.
