# Nolane Video Command Center

## Mission
Restore project state, understand the brief, route through the 33 internal skills, use the smallest useful toolset, inspect real outputs and preserve evidence-rich handoff.

## Route before renderer
Read repository state, genre routing, tool inventory and asset policy first. Search the existing resource pool before AI media generation or external downloads. The Build 76 resource release is already above 50 GB globally unique and contains about 1.14 GB of category-level audio ZIPs (some recordings, some synthetic). Its exact asset/source manifests separate creators and rights; do not infer suitability from an archive name.

### Illustrated/cartoon history route
When the user supplies or requests polished 2D/cartoon historical explainers with expressive character acting, distinct historical locations, horse/weapon/world cycles, animated maps, portrait/stat cards, myth/fact explainers, historical artwork and layered editorial motion, route first to `illustrated-history-animation-director`. This is distinct from both a footage-led cinematic documentary and H2 Squire. Select H2 rigs, Remotion, Motion Canvas, Krita or Blender per shot; keep character design and animation original. Build a whole-runtime reference map and dense motion samples around important actions, then record the exact scope of what was inspected.

### Cinematic historical documentary route
When the user wants sweeping cinematic history, footage-led documentary craft, archival evidence, 2.5D/3D reconstruction or a live-action-inspired reference, route first to `historical-cinematic-documentary-director`. Use a paper edit → radio edit → picture edit workflow. Pick Remotion, Blender, Three.js/GSAP, Krita, archival footage and compositing per shot. Require timecoded camera/motion/audio notes; full normal-speed playback/listening is required for final artistic approval.

### Historical military animation / Squire route
Only when the user explicitly asks for H2 Squire/vector style or an existing Squire series (symbolic round-headed characters, vector formations and tactical diagrams), route to `historical-military-animation-director` and the separately activated private h2-squire-studio specialist. Do not default to Squire simply because the subject is a historic battle or the engine is available.

### Other video routes
Use the established cinematic stick-figure narrative style only when that style is selected by the user or belongs to the existing series. Match documentary, product, explainer, social and motion-graphic formats to their actual purpose; do not impose one universal look.

## Audio policy
Before unpacking audio archives, search `audio-library/generated/preview-catalog.json` and `audio-library/generated/meta-preview-catalog.json` for candidates by tag/category, title, material, action, perspective and rights class. Prefer exact catalog hits and audition them in the offline preview bank; then fetch only the relevant source pack/member. Use recorded and licensed sound first.
Use recorded and licensed sound first. Search the existing audio index/bundles, inspect rights and technical metadata, compare and audition several candidates, then layer and synchronize. Procedural synthesis is a temporary placeholder or a documented exception—not the default soundtrack. Keep score, ambience, Foley, impacts, narration, transitions and stems distinct until mix. Route acquisition and rights separation through `historical-audio-library-curator`; use `audio-postproduction-engineer` for per-shot cue design, stem mix and mastering.

## Motion and QA
Every key shot must name camera path, subject/prop action, depth layers and edit motivation. For motion-led work, actor, prop, environment, camera and graphic motion are separate channels; camera zoom alone is not action. Prototype the hardest action and transition and make a representative picture/sound sample before scaling. Motion must be deterministic under arbitrary frame seeks. Require continuous full-length picture-and-sound review and a timecoded defect log. Do not infer artistic approval from CI or contact sheets.

## Repository safety
- Primary repo: Nolane-x/video.
- The asset library has already exceeded the 50 GB unique-resource target. Prioritize audio/visual category gaps and usable discovery, not broad byte growth.
- Production routes may read the asset catalogue/Releases; only mutate the source catalogues/downloaders/asset build workflows when the user explicitly assigns that work. Keep changes limited to the assigned lane.
- Separate public CC0/Public Domain redistribution from item-specific project-use and private production-only sources. Do not put unredistributable raw sound files in public GitHub Releases.
- Never overwrite an existing master. Render a distinct candidate, preserve source/checksum and require explicit approval before merge or promotion.
- Plugin activation is host-controlled. Do not claim hidden plugin-to-plugin calls.
