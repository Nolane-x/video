# Nolane Video Command Center

## Mission
Restore project state, understand the brief, route through the 31 internal skills, use the smallest useful toolset, inspect real outputs and preserve evidence-rich handoff.

## Route before renderer
Read repository state, genre routing, tool inventory and asset policy first. Search the existing resource pool before AI media generation or external downloads. The current Build 76 resource release contains a rich video/photo/3D pool and about 1.14 GB of distinct audio bundles; the source map lives in audio-library/SOURCES.json. These source records have per-item rights, not a blanket license.

### Cinematic historical documentary route
When the user wants sweeping cinematic history, footage-led documentary craft, high camera/motion variety, archival evidence, 2.5D/3D reconstruction or the style of a supplied moving reference, route first to historical-cinematic-documentary-director. Use a paper edit → radio edit → picture edit workflow. Pick Remotion, Blender, Three.js/GSAP, Krita, archival footage and compositing per shot. Require full reference playback with sound and a timecoded shot/motion/audio log; if inspection is blocked, state that clearly.

### Historical military animation / Squire route
Only when the user explicitly asks for H2 Squire/vector style or an existing Squire series (symbolic round-headed characters, vector formations and tactical diagrams), route to historical-military-animation-director and the separately activated private h2-squire-studio specialist. Do not default to Squire simply because the subject is a historic battle or the engine is available.

### Other video routes
Use the established cinematic stick-figure narrative style only when that style is selected by the user or belongs to the existing series. Match documentary, product, explainer, social and motion-graphic formats to their actual purpose; do not impose one universal look.

## Audio policy
Use recorded and licensed sound first. Search the existing audio index/bundles, inspect license and metadata, audition multiple candidates, then layer and synchronize. Procedural synthesis is a temporary placeholder or a documented exception—not the default soundtrack. Keep score, ambience, Foley, impacts, narration, transitions and stems distinct until mix.

## Motion and QA
Every key shot must name camera path, subject/prop action, depth layers and edit motivation. Prototype the hardest shot and a 30–60 second picture/sound sample before scaling. Motion must be deterministic under arbitrary frame seeks. Require continuous full-length picture-and-sound review and a timecoded defect log. Do not infer artistic approval from CI or contact sheets.

## Repository safety
- Primary repo: Nolane-x/video.
- The parallel resource-library agent exclusively owns video-library/**, global source catalogs, downloaders, packagers/importers and the Build 76 release workflow. Production may read and use existing published assets but must not mutate that workstream.
- Never overwrite an existing master. Render a distinct candidate, preserve source/checksum and require explicit approval before merge or promotion.
- Plugin activation is host-controlled. Do not claim hidden plugin-to-plugin calls.
