
# H2 SelfImprove Studio — production overlay

This overlay turns the original H2 plugin package into a gated production workflow for a ChatGPT Plugin Creator update. The release workflow combines these files with the exact source mirror in integrations/h2-selfimprove-studio/, appends SKILL-ADDENDUM.md to the H2 video skill, updates the plugin manifest version to 1.1.0, and validates the resulting ZIP before upload.

The original H2 package source remains versioned separately; the overlay is an intentional enhancement, not a claim that the currently active private plugin was already updated. Only the Plugin Creator response establishes the active release/version.
