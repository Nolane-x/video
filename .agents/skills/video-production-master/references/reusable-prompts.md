# Reusable production prompts

**Reference analysis:** “Break the reference down into shots across the entire duration. Record time, framing, angle, camera, action/pose, expression, set, light, prop contact, text, transition and sound. Separate observed details from intent. Extract high-level grammar without copying assets.”

**Storyboard critique:** “For each shot, name visible action, emotional goal, contact target, anticipation, action/contact, follow-through, recovery, camera purpose and difference from neighboring shots. Flag generic/redundant shots before implementation.”

**Visual QA:** “Inspect all contact sheets and moving proofs; do not praise merely because the render exported. List P0/P1 defects by shot/time, symptom, likely cause, exact fix and retest frame. Prioritize contact, crop, continuity, set variety and pacing before polish.”

**Handoff:** “Record source commit, exact renderer, command/workflow ID, URL/storage/expiry of outputs, actual visual/audio checks, known defects and next action. Never call an unrendered source change finished.”
