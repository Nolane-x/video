## Search both generated indexes with one command

Run from the repository root:

```bash
python tools/audio/search_audio_resources.py --query "katana sword clash"
python tools/audio/search_audio_resources.py --query "horse hooves dirt" --kind foley
python tools/audio/search_audio_resources.py --query "piano note" --kind instrument --json
```

This searches Build 76 and Meta Open Sound in one pass. By default it excludes records in rights-review/source-only categories, carries required CC-BY attribution, and keeps the human audition/final-use gate. Search is discovery only; it does not approve a sample.

## Historical sound taxonomy

Build tags/search collections for:
- Horses: walk, trot, gallop, rear, hoof impacts on dirt/stone/wood, tack, saddle leather, snort and whinny.
- Combat: sword draw, blade clash/scrape, armor/chain movement, shield hit, bowstring, arrow release/flight/impact, spear/staff movement and distant battle beds.
- Crowd/command: crowd walla, chant, cheer, panic, shouted commands, marching cadence and group movement at near/mid/far distances.
- Environment: wind, rain on roof/wood/cloth, thunder, fire, forest, birds/insects, river, surf, harbor, ship creak, rigging, sails, oars and deck footsteps.
- Social history: market, workshop/blacksmith, woodwork, paper/scroll, calligraphy brush, doors, pottery, food preparation and indoor room tone.
- Music: period-context instrument textures only when supported by research; otherwise use evocative licensed scoring without claiming historical authenticity. Prepare intro, tension, action, loss, reflection and resolution variants.
- Editorial: transitions, risers, impacts and UI accents as a small supplemental category.

## External acquisition routes

### Public redistributable
- OpenGameArt: require the item's own License(s) field to expose exactly one CC0 1.0 link.
- Openverse: query the audio API with license=cc0; recheck exact item license and license URL; retain creator and landing page; validate signature and hash.
- Wikimedia Commons: use file-level LicenseShortName and LicenseUrl; only exact CC0/Public Domain. Do not infer from the collection.
- USGS: accept only the exact per-item Public Domain label and preserve credit.
- Kenney: individual packs such as Digital Audio are listed as CC0; follow the official download flow rather than guessing a ZIP URL.

### Project-use / private only
- Sonniss GDC 2026 advertises a 7.47 GB+ pack with 347+ files. The current EULA v2.0 (effective 27 Aug 2026) permits commercial/personal synchronization into films and videos without attribution, but prohibits raw sound resupply/resale and AI/ML training. Use as a private production-only library; never commit its raw sounds to public GitHub or shared resource ZIPs. Record exact EULA version and download date. Official download: https://gdc.sonniss.com/ ; EULA: https://sonniss.com/gdc-bundle-license/.
- Mixkit is project-use/source-only by default. Verify the exact item and license, and do not mirror raw stock files into public library archives.

## Inventory and mix policy

1. Search existing volumes before any new acquisition.
2. Keep originals lossless; create processed copies for editing.
3. Inventory fields: ID, title, creator, semantic tags, duration, channels, sample rate, bit depth, peak/LUFS, SHA-256, source page, exact file URL, license text/URL/version, download date and rights class: public_cc0_pd, project_use_only, private_production_only or blocked.
4. Keep private/project-use files out of public ZIPs. Do not merge Sonniss or restricted Mixkit source files into redistributable packs.
5. Make a per-shot cue sheet with narration, ambience, Foley, spot SFX, music and silence on separate lanes. Sync to visible contact and vary perspective/distance.
6. Every candidate must be auditioned by a human before it can be marked production-ready. Metadata alone cannot prove that a sound fits.
7. Listen to the complete final film at normal speed; log timecoded issues, measure LUFS/LRA/true peak and retain separate PCM stems.

The five non-synthetic Build 76 packs are the starting point for real recordings. Keep NASA in its distinct rights bucket. Treat procedural audio as fallback/supplement only.
