## How to hand off safely
1. State the task boundary and the exact repository/branch/project file paths.
2. Name the internal skill or specialist plugin that owns the next stage.
3. Pass the source facts, tool versions, existing tests/artifacts and acceptance criteria; do not ask the user to repeat established constraints.
4. The specialist plugin must read the repository's actual installed version and source registry, not rely on this index alone.
5. Return the specialist's changes/evidence to the Command Center for integration and end-to-end review.
6. Keep user approval gates for merges, paid APIs, model downloads, asset workstream changes and production writes.

## Activation boundary

This is a static registry and handoff guide. Plugin switching/activation is controlled by the ChatGPT host and the user. No claim is made that the currently selected plugin can invoke another private plugin's tools or skills in the background.
