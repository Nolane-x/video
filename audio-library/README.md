# Nolane Historical Audio Library

This directory is the semantic index and working policy for historical/illustrated video sound. It does not contain raw licensed media. Download the source packs from the Build 76 GitHub Release using SOURCES.json.

## Workflow
1. Search SOURCES.json for a source lane, category and rights class.
2. Download only the corresponding GitHub Release ZIP.
3. Extract into a private working folder; do not commit raw archives or private/project-use sounds here.
4. Inspect the item's source page, credit and license record in the archive index.
5. Audition candidates, then record your selection and audition status in the shot cue sheet.
6. Keep the original file and SHA-256. Store processed edit copies separately.
7. Export stems and full mix; listen to the full picture/sound before approval.

For detailed acquisition conditions and sound taxonomy, read docs/audio/HISTORICAL_SOUND_LIBRARY.md. The supplied Samurai reference study is in docs/reference-studies/samurai-history-animation-review-2026-11-06.md.
